# MatchCentre
Lacrosse Club Match Centre Wordpress Plugin

A complete WordPress plugin for displaying lacrosse league data from GameDay. This plugin includes:
- Built-in PHP scraper to fetch data directly from GameDay
- WordPress widgets and Gutenberg blocks to display ladders, upcoming games, and results
- Team-specific blocks with multi-team support
- Competition discovery tools (admin UI, WP-CLI, and PHP script)
- Easy-to-use admin interface with one-click data fetching

## Features

- 📊 **Competition Ladder** - Display current season standings
- 📅 **Upcoming Games** - Show scheduled matches
- 🏆 **Recent Results** - Display completed games with scores
- 🔄 **Integrated Scraper** - Fetch data directly from GameDay with one click
- ⚡ **Data Caching** - Efficient caching to reduce load times
- 🧩 **Blocks + Widgets** - Gutenberg blocks and classic widgets
- 🧑‍🤝‍🧑 **Team Blocks** - Team Results and Team Upcoming with multi-team sections
- 🧭 **Competition Discovery** - Find IDs from GameDay automatically
- 🎠 **Results Carousel** - Results/upcoming blocks auto-scroll to latest
- 🎨 **Responsive Design** - Mobile-friendly widgets
- ⚙️ **Easy Configuration** - Admin settings page for easy setup
- 🏅 **Multiple Competitions** - Support for multiple competitions
